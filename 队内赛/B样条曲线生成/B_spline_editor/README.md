# Robocon B 样条路径规划编辑器

## 安装与运行

在项目目录中执行：

```powershell
cd B_spline_editor
pip install -r requirements.txt
python main.py
```

如果系统没有配置 `python` 命令，请使用 Python 的完整路径，例如：

```powershell
C:\Users\HP\AppData\Local\Programs\Python\Python314\python.exe main.py
```

本项目已针对当前电脑的 Python 3.14 配置。也可以直接双击 `启动路径编辑器.bat` 启动。

## 默认比赛场地

程序启动后会自动加载程序目录中的 `field_default.png`，无需再次手动导入。

- 默认场地尺寸：`11000 mm x 11000 mm`，即规则书规定的围栏内部场地。
- 默认场地图已经裁剪为完整场地，并按 11000 mm 标定。
- 若替换背景图片，需重新输入对应的实际场地宽度和长度。

## 使用方法

- 点击“导入场地图片”，选择比赛场地平面图；然后填写场地实际宽度和长度，单位为 mm。
- 默认场地图中，机器人世界坐标系原点位于左下角蓝色启动区的左下角；X 轴向右，Y 轴向上。
- 机器人正前方按 **+Y 轴**处理。导出的 `theta` 均为 yaw 角：以 +Y 为 0，逆时针为正，单位 rad。
- 图中的 X、Y 坐标轴以 cm 显示，并贴合场地图片的左边和下边；控制点表格与导出数据仍使用 mm。
- 在场地空白处左键单击可添加控制点；按住控制点左键拖动可修改位置；在控制点上右键单击可删除。
- 左侧表格实时显示所有控制点的机器人坐标，单位为 mm。双击 X 或 Y 单元格可直接输入坐标，按 Enter 后立即更新路径。
- 至少添加 4 个控制点后，程序生成三阶夹持 B 样条曲线。修改“采样间隔”可控制离散路径点间距。
- 采样方式可切换为“按采样间隔”或“指定路径点数量”。后者会精确生成设置数量的路径点。
- 在“速度规划”中设置横向加速度、速度比例、起步加速度和刹车减速度。横向加速度只用于曲率限速；起步和刹车约束会使首尾路径点速度为零。
- 在“MPC 状态量”中设置采样周期 `dt`（默认 `0.01 s`），程序会按时间重新采样曲线状态，并显示状态数与总时长。
- 点击“复制 MPC 数组”或“导出 MPC .h”可把时间采样后的参考状态交给控制器；点击“导出 MPC .csv”可用于 MATLAB/Python 离线分析。
- 点击“复制 C 数组到剪贴板”可直接粘贴到 STM32 工程；点击“导出 .h 文件”可保存为按距离采样的路径头文件。

## MPC 状态量（按时间采样）

`path.h` 中的路径点按距离采样，而 MPC 通常需要固定控制周期的参考轨迹。程序根据速度规划结果，把同一条曲线重新按时间采样：

- 根据相邻路径点的速度，以匀加速假设计算每一段的通过时间 `2 * ds / (v0 + v1)`，得到整条曲线的总时长 `T`。
- 从 `t = 0` 开始，以固定周期 `dt` 生成状态；默认 `dt = 0.01 s`，可在 `0.001 s` 到 `1.0 s` 之间调节，修改后立即重新生成。
- 当 `T` 不是 `dt` 的整数倍时，会在路径终点补一个状态，因此除最后一个状态外，相邻状态的时间间隔恒为 `dt`。
- 时间采样在相邻路径点之间按弧长线性插值；需要更精细的几何参考时，可减小“采样间隔”（例如改为 `20 mm`），状态数仍由总时长和 `dt` 决定。
- `theta` 为 yaw 角（+Y 正前方为 0，逆时针为正），并沿路径展开为连续角度（跨 `±π` 不会跳变），便于 MPC 直接使用。
- 左侧面板显示“状态数”和“总时长”；勾选“在图中显示时间采样点”后，曲线上的橙色圆点即为时间采样位置（点数过多时只做显示抽稀，不影响导出数据）。
- 时间采样依赖于速度曲线。若“速度比例”为 0 或速度曲线全为 0，程序会在面板中提示无法生成，此时请先调整速度规划参数。

导出的 MPC C 数组结构为：

```c
typedef struct
{
    float t;      /* s     当前状态对应的时间 */
    float x;      /* mm    机器人坐标 X */
    float y;      /* mm    机器人坐标 Y */
    float theta;  /* rad   机器人 yaw，+Y 正前方为 0，逆时针为正，已连续展开 */
    float v;      /* m/s   切向速度 */
    float omega;  /* rad/s 参考角速度，v * kappa */
    float accel;  /* m/s^2 纵向加速度 */
    float kappa;  /* 1/m   曲率 */
    float s;      /* mm    累计弧长 */
} MpcState;

#define MPC_SAMPLE_TIME 0.010000f
#define MPC_STATE_COUNT 542
```

CSV 文件的列依次为：

```text
step,time_s,x_mm,y_mm,theta_rad,v_mps,omega_radps,accel_mps2,kappa_1pm,s_mm
```

## 配置保存与恢复

- 点击“保存配置”会将控制点、场地尺寸、采样参数、速度规划参数和 MPC 采样周期写入 `.json` 文件。默认目录为 `B_spline_editor/saved_paths/`，也可以在对话框中选择其他位置。
- 点击“打开配置”并选择此前保存的 `.json` 文件，即可恢复这些编辑器设置并重新生成路径。
- 配置文件版本已升级到 3；旧版本（1、2）的配置文件仍可打开，缺少 MPC 参数时自动使用 `0.01 s`。
- `.json` 配置文件只用于路径编辑器；给控制器工程使用的离散路径仍通过“导出 .h 文件”生成。

## 导出数据说明

按距离采样的导出数组每个元素均为：

```c
{x, y, theta, curvature, s, velocity}
```

- `x`、`y`：机器人坐标，单位 mm。
- `theta`：机器人 yaw 角，单位 rad；以机器人正前方（+Y 轴）为 0，逆时针为正，保留 3 位小数。
- 如果旧控制器仍把 `theta` 当作 `atan2(dy, dx)` 的切线角（例如直接算 `cos(theta)`、`sin(theta)`），需要改成 `theta + π/2`。`config/defaults.py` 中的 `FORWARD_AXIS_ANGLE` 可修改正前方对应的角度（+Y 为 `π/2`，+X 为 `0`）。
- `curvature`：带符号曲率，单位 `1/m`，保留 3 位有效数字。
- `s`：从路径起点开始的累计距离，单位 mm；`x`、`y`、`s` 导出时均保留整数。
- `velocity`：该点的期望切向速度，单位 `m/s`。它不超过 `2.5 m/s`，同时受曲率、全局速度比例、起步和刹车约束。

按时间采样的 MPC 数组字段见上一节。两套数组使用相同的机器人坐标系和单位，可直接对照。
