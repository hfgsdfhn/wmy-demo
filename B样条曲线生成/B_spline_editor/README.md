# Robocon B 样条路径规划编辑器

## 安装与运行

在项目目录中执行：

```powershell
cd B_spline_editor
pip install -r requirements.txt
python main.py
```

如果系统没有配置 `python` 命令，请使用 Python 的完整路径，例如：

```powershell
C:\Users\HP\AppData\Local\Programs\Python\Python313\python.exe main.py
```

本项目已针对当前电脑的 Python 3.14 配置。也可以直接双击 `启动路径编辑器.bat` 启动。

## 默认比赛场地

程序启动后会自动加载上一级目录中的 `屏幕截图 2026-08-02 104037.png`，无需再次手动导入。

- 默认场地尺寸：`11200 mm x 6100 mm`。
- 默认尺寸以规则中的 `700 mm x 700 mm` 蓝色启动区和 `1400 mm x 400 mm` 存块区为基准，和所提供场地图的像素比例一致。
- 若替换背景图片，需重新输入对应的实际场地宽度和长度。

## 使用方法

- 点击“导入场地图片”，选择比赛场地平面图；然后填写场地实际宽度和长度，单位为 mm。
- 默认场地图中，机器人世界坐标系原点位于左下角蓝色启动区的左下角；X 轴向右，Y 轴向上。
- 图中的 X、Y 坐标轴以 cm 显示，并贴合场地图片的左边和下边；控制点表格与导出数据仍使用 mm。
- 在场地空白处左键单击可添加控制点；按住控制点左键拖动可修改位置；在控制点上右键单击可删除。
- 左侧表格实时显示所有控制点的机器人坐标，单位为 mm。双击 X 或 Y 单元格可直接输入坐标，按 Enter 后立即更新路径。
- 至少添加 4 个控制点后，程序生成三阶夹持 B 样条曲线。修改“采样间隔”可控制离散路径点间距。
- 采样方式可切换为“按采样间隔”或“指定路径点数量”。后者会精确生成设置数量的路径点。
- 在“速度规划”中设置横向加速度、速度比例、起步加速度和刹车减速度。横向加速度只用于曲率限速；起步和刹车约束会使首尾路径点速度为零。
- 点击“复制 C 数组到剪贴板”可直接粘贴到 STM32 工程；点击“导出 .h 文件”可保存为头文件。

## 导出数据说明

导出数组的每个元素均为：

```c
{x, y, theta, curvature, s, velocity}
```

- `x`、`y`：机器人坐标，单位 mm。
- `theta`：路径航向角，单位为 rad，相对机器人 X 正方向逆时针为正，保留 3 位小数。
- `curvature`：带符号曲率，单位 `1/m`，保留 3 位有效数字。
- `s`：从路径起点开始的累计距离，单位 mm；`x`、`y`、`s` 导出时均保留整数。
- `velocity`：该点的期望切向速度，单位 `m/s`。它不超过 `2.5 m/s`，同时受曲率、全局速度比例、起步和刹车约束。
